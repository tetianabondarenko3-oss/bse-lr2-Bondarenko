# Діаграма прецедентів (Use Case)

Тут представлено опис акторів системи та діаграму прецедентів для системи "Touch Up Smart".

## Актори системи
* Гість (Guest): незареєстрований користувач, може переглядати базові функції (вибір категорії, обмежений перегляд карток)
* Користувач (User): зареєстрований користувач із повним доступом до функцій: вибір категорії, перегляд карток, додавання в «Обране», редагування профілю
* Адміністратор (Admin): відповідає за модерування контенту: додавання, редагування або видалення фактів у базі

## Код діаграми
```puml
@startuml
left to right direction

actor "Гість" as Guest
actor "Користувач" as User
actor "Адміністратор" as Admin

rectangle "Система Touch Up Smart" {
  usecase "Вибір категорії події" as UC01
  usecase "Генерація карток фактів" as UC02
  usecase "Перегляд карток" as UC03
  usecase "Реєстрація / Вхід" as UC04
  usecase "Збереження в Обране" as UC05
  usecase "Редагування профілю" as UC06
  usecase "Модерування контенту" as UC07
  usecase "AI генерація контенту" as UC08
}

Guest --> UC01
Guest --> UC03
Guest --> UC04

User --> UC01
User --> UC03
User --> UC05
User --> UC06

Admin --> UC07

UC01 ..> UC02 : <<include>>
UC05 ..> UC04 : <<include>>
UC06 ..> UC04 : <<include>>
UC07 ..> UC04 : <<include>>

UC02 ..> UC08 : <<extend>>
@enduml
