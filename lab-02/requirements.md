# Функціональні вимоги до системи

| ID | Функціональна вимога | Пріоритет |
| :--- | :--- | :--- |
| FR-01 | **Вибір категорії події.** Система дозволяє користувачеві обрати категорію майбутньої події (наприклад, «бізнес-зустріч», «свято», «спорт» тощо). Це гарантує, що отримані факти будуть відповідними контексту заходу.  | Високий |
| FR-02 | **Генерація карток фактів.** Після вибору категорії система автоматично генерує набір карток з фактами або питаннями відповідно до обраної теми. Кожна картка містить релевантну інформацію, що допомагає підвищити ерудицію користувача в цій темі.  | Високий |
| FR-03 | **Перегляд карток.** Користувач може переглядати згенеровані картки одна за одною. Наприклад, свайпом або кліком відображається наступний факт/питання. Це дозволяє плавно переглянути весь набір інформації (потрібно чітко перевірити, що механізм переходу між картками працює). | Високий |
| FR-04 | **Реєстрація користувача.** Система дозволяє новому користувачеві створити обліковий запис, вказавши унікальний email та пароль, для доступу до персоналізованих функцій. | Високий |
| FR-05 | **Збереження в «Обране».** Користувач може оновити свої персональні дані й інтереси (наприклад, змінити пріоритетні категорії, ім’я тощо). Це забезпечує адаптацію під власні вподобання (важливо, щоб зміни зберігалися та відображалися).  | Середній |
| FR-06 | **Редагування профілю.** Користувач може оновити свої персональні дані й інтереси (ім’я, пріоритетні категорії тощо). | Середній |
| FR-07 | **Модерування контенту.** Адміністратор системи може переглядати і редагувати факти (картки) у базі даних для забезпечення якості інформації. Тобто передбачена роль адміністратора з можливістю уточнення або видалення фактів (необхідно перевірити доступ адміна до відповідних функцій). | Низький |
| FR-08 | **Інтеграція з AI.** Система за потреби використовує штучний інтелект для генерації або доповнення контенту (нових фактів, підказок, формулювань) під час підготовки матеріалів. Ця вимога допомагає автоматизувати оновлення бази знань (перевірка чи викликаються AI-сервіси при генерації нових карток). | Високий |
